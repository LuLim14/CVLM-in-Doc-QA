# Usage

Start with the [README](README.md) for the method, reported results, and
installation. Follow the [reproduction guide](docs/reproduction.md) for the
paper configuration, training, evaluation, and matched-reader baselines.

The shell wrappers in `scripts/` and the cluster recipes in `hse/` retain
historical defaults. They are not the paper reproduction entrypoints. Use the
explicit commands in the reproduction guide for the reported protocol.
