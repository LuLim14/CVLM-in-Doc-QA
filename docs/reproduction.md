# Reproduction guide

Run commands from the repository root in a Bash shell, after installing the dependencies described in the README. The training recipe uses Linux, an NVIDIA GPU, and Python 3.11. CPU unit tests exercise the implementation without downloading model weights. They do not validate full training on CPU.

## What this release contains

The release includes the training and evaluation implementation, reader baselines, LLMLingua-2 selection and audit tools, diagnostic utilities, and unit tests. It does not include trained model checkpoints, the original per-example evaluation dumps, or the original cluster run directories. Training or obtaining a compatible checkpoint is required before running checkpoint evaluation. Numerical tables in the paper are reported measurements, not outputs regenerated by this release packaging step.

The main entrypoints are `src/train_cvlm.py`, `src/train_sft.py`, and `src/eval_cvlm.py`. Historical launch scripts and research utilities retain experiment-specific assumptions. The explicit commands below avoid their cluster paths and environment defaults.

## Models and data

| Component | Identifier |
| --- | --- |
| Document encoder | `answerdotai/ModernBERT-base` |
| Main decoder | `HuggingFaceTB/SmolLM2-1.7B-Instruct` |
| Mixer configuration | `google/vit-base-patch16-224` |
| QA dataset | `sggetao/PwC` |
| LLMLingua-2 selector | `microsoft/llmlingua-2-xlm-roberta-large-meetingbank` |

PwC provides the fields `input` for the document, `prompt` for the question, and `answer` for the target. Models and data are downloaded from their respective providers. Their licenses and access conditions apply separately from this repository.

The main held-out slice, FRESH, is `test[2100:5100]`. It contains 3,000 QA rows from 205 documents in the reported experiment. Filtering uses at most 1,024 encoder tokens for the source, 512 decoder tokens for the question, and 1,024 decoder tokens for the answer. Verify the retained row count when downloading a new dataset version. The release does not pin an original dataset revision.

The pooling factor `cr` counts encoder tokens per latent. It is not a measured ratio of decoder tokens. Retention baselines receive a document-token cap of `min(ceil(L_encoder / cr), 1024)` in decoder-token units. The question is retained. Whole-word and sentence selectors may leave some of that cap unused.

## Train Pool+Project

The paper uses three epochs, batch size 64 on one accelerator, learning rate `1e-4`, 100 warmup updates, a constant learning rate after warmup, AdamW with zero weight decay, and gradient clipping at 1.0. The decoder is trainable. The top 22 ModernBERT blocks and final normalization are unfrozen. Four zero-initialized pooling queries are averaged to emit one latent per chunk. They remain symmetric in the inspected paper checkpoints.

Clear inherited experiment settings before starting:

```bash
unset CR_SCHEDULE EVAL_CR_SCHEDULE EVAL_ALL_CHECKPOINTS
unset MIXED_CR_SET MIXER_DEPTH_MAP MIXED_FIDELITY_P
export TRACKIO_DISABLE=1
export TOKENIZERS_PARALLELISM=false
mkdir -p runs results selections
```

```bash
python src/train_cvlm.py \
  --output_dir runs/pool_project_s43 \
  --dataset_name sggetao/PwC \
  --dataset_split train \
  --model_name_or_path HuggingFaceTB/SmolLM2-1.7B-Instruct \
  --text_encoder_name answerdotai/ModernBERT-base \
  --vision_encoder_name google/vit-base-patch16-224 \
  --no_vit true \
  --vit_init pretrained \
  --vit_num_layers 0 \
  --freeze_vit false \
  --mean_pool false \
  --legacy_projector false \
  --mask_vit_padding false \
  --vit_apply_final_layernorm true \
  --compact_decoder_positions false \
  --fp32_master_weights false \
  --unfreeze_encoder_top_k 22 \
  --num_pool_latents 4 \
  --compression_rate 1 \
  --cr_schedule '1:1500,2:3000,4:4500,8:6000,16:0' \
  --max_prompt_len 512 \
  --max_answer_len 1024 \
  --max_source_len 1024 \
  --max_vision_len 1024 \
  --epochs 3 \
  --batch_size 64 \
  --gradient_accumulation_steps 1 \
  --lr 1e-4 \
  --enable_warmup \
  --warmup_steps 100 \
  --disable_lr_schedule true \
  --gradient_checkpointing true \
  --grad_clip 1.0 \
  --save_interval_steps 1000 \
  --seed 43 \
  --trackio_disable
```

Seed 43 is used here for a new run under the deterministic epoch sampler in this code. The paper's discovery run used seed 42 under an earlier sampler implementation. Passing seed 42 to this version does not recreate that original batch order. Seeds 43 and 44 were used in paired depth replications. The system-level Pool+Project replications are a separate campaign, as described in the paper.

The trainer saves `model_step_*.safetensors`, optimizer/RNG state, an initialization manifest, CSV metrics, and mechanistic probe artifacts. Keep the manifest with the checkpoint. Checkpoints contain trainable parameters and require the original base model identifiers to reconstruct frozen parameters. A checkpoint labeled step 11,326 corresponds to 11,325 updates in the paper's counter convention. Use the actual checkpoint emitted by your run.

Reducing the microbatch and increasing gradient accumulation can help with memory, but that is a changed execution setting. The published protocol uses batch 64 without accumulation. The measured inference memory in the paper is not the training-memory requirement.

## Architecture ablations

Start from the training command above, change its output directory, and replace the indicated options. Use the same architecture options at evaluation time.

| Variant | Options |
| --- | --- |
| Pool+Project | `--no_vit true --mean_pool false --vit_num_layers 0` |
| MeanPool+Project | `--no_vit true --mean_pool true --vit_num_layers 0` |
| Pool+1L Mixer | `--no_vit false --mean_pool false --vit_init random --vit_num_layers 1` |
| Pool+12L Mixer | `--no_vit false --mean_pool false --vit_init random --vit_num_layers 12` |
| Pretrained mixer | `--no_vit false --vit_init pretrained --vit_num_layers 12` |

`vit_num_layers=0` means the full configured stack when `no_vit=false`. Bypass is selected with `no_vit=true`. The ordinary one-layer comparison uses `vit_num_layers`, not the separately implemented gated `mixer_depth_map` feature.

Masking, final LayerNorm, projector normalization, decoder positions, and optimizer precision are experimental settings. The example preserves the legacy settings used for the paired comparisons. Changing them requires a new controlled comparison. The architecture manifest checks several of these options when loading a checkpoint.

## Evaluate a compressor at cr=8 and cr=16

Supply a trained checkpoint and keep its `initialization_manifest.json` in the same directory. The following evaluates the same checkpoint at both rates. A rate sweep and a curriculum-stage comparison answer different questions, so record the checkpoint used with each result.

```bash
unset EVAL_CR_SCHEDULE EVAL_ALL_CHECKPOINTS
export CVLM_CHECKPOINT=/absolute/path/to/model_step_11326.safetensors

for cr in 8 16; do
  python src/eval_cvlm.py \
    --mode cvlm \
    --checkpoint_path "$CVLM_CHECKPOINT" \
    --dataset_name sggetao/PwC \
    --dataset_split 'test[2100:5100]' \
    --model_name_or_path HuggingFaceTB/SmolLM2-1.7B-Instruct \
    --text_encoder_name answerdotai/ModernBERT-base \
    --vision_encoder_name google/vit-base-patch16-224 \
    --no_vit true \
    --vit_init pretrained \
    --vit_num_layers 0 \
    --freeze_vit false \
    --mean_pool false \
    --legacy_projector false \
    --mask_vit_padding false \
    --vit_apply_final_layernorm true \
    --compact_decoder_positions false \
    --num_pool_latents 4 \
    --compression_rate "$cr" \
    --max_prompt_len 512 \
    --max_answer_len 1024 \
    --max_source_len 1024 \
    --max_vision_len 1024 \
    --batch_size 8 \
    --max_samples 0 \
    --seed 42 \
    --trackio_disable \
    --output_json "results/pool_project_cr${cr}.json" \
    --dump_per_sample "results/pool_project_cr${cr}_dump.jsonl"
done
```

Teacher-forced perplexity is `exp(sum(answer_nll_nats) / sum(answer_tokens))`. Token accuracy is `sum(correct_tokens) / sum(answer_tokens)`. These are pooled answer-token statistics. Averaging per-example perplexities produces a different estimator.

Setting `max_source_len=0` makes the source-length filter depend on `cr * max_vision_len`. Always use the fixed cap above when comparing rates. Evaluation also reads `EVAL_CR_SCHEDULE` and `EVAL_ALL_CHECKPOINTS` from the environment. Clearing those variables avoids accidentally enabling a checkpoint sweep or requesting a schedule with a single checkpoint.

## Train and evaluate matched retention readers

Each retention policy has its own trained decoder. Train separately for `cr=8` and `cr=16`. The example below trains the first-N reader at `cr=8`:

```bash
python src/train_sft.py \
  --output_dir runs/first_n_cr8 \
  --dataset_name sggetao/PwC \
  --dataset_split train \
  --model_name_or_path HuggingFaceTB/SmolLM2-1.7B-Instruct \
  --text_encoder_name answerdotai/ModernBERT-base \
  --selection_policy first \
  --truncate_cr 8 \
  --max_prompt_len 512 \
  --max_answer_len 1024 \
  --max_source_len 1024 \
  --max_vision_len 1024 \
  --epochs 3 \
  --batch_size 64 \
  --gradient_accumulation_steps 1 \
  --lr 1e-4 \
  --lr_scheduler_type constant_with_warmup \
  --enable_warmup \
  --warmup_steps 100 \
  --grad_clip 1.0 \
  --gradient_checkpointing \
  --save_interval_steps 1000 \
  --seed 42 \
  --trackio_disable
```

```bash
unset EVAL_CR_SCHEDULE EVAL_ALL_CHECKPOINTS
python src/eval_cvlm.py \
  --mode sft \
  --sft_model_path runs/first_n_cr8 \
  --dataset_name sggetao/PwC \
  --dataset_split 'test[2100:5100]' \
  --model_name_or_path HuggingFaceTB/SmolLM2-1.7B-Instruct \
  --text_encoder_name answerdotai/ModernBERT-base \
  --compression_rate 1 \
  --max_prompt_len 512 \
  --max_answer_len 1024 \
  --max_source_len 1024 \
  --max_vision_len 1024 \
  --batch_size 8 \
  --doc_truncation first \
  --doc_budget_cr 8 \
  --seed 42 \
  --trackio_disable \
  --output_json results/first_n_cr8.json \
  --dump_per_sample results/first_n_cr8_dump.jsonl
```

For BM25, use `--selection_policy query` in training and `--doc_truncation query` in evaluation, with new output paths. This is the included question-conditioned sentence selector with `k1=1.5`, `b=0.75`, greedy budget allocation, and selected sentences restored to document order. The archived matched-BM25 evaluation uses `--no_bf16`; record the numerical mode rather than assuming all historical reader evaluations used identical precision.

For `cr=16`, change `truncate_cr` and `doc_budget_cr` to 16 and train a separate reader. Retention readers train at their fixed budget. They do not follow the compressor's rate curriculum.

For frozen-reader controls, use `--mode baseline_llm_full` without a CVLM checkpoint or SFT model path. `--doc_truncation first --doc_budget_cr 8` selects first-N. `--doc_truncation none` supplies the full document. The full-document frozen reader is a reference with a different context budget and training status. `--mode baseline_llm` is a question-only control, not raw-document truncation.

## LLMLingua-2 selections and matched readers

The selector adapter targets `llmlingua==0.2.2`. It searches a continuous percentile threshold while retaining the library's scorer and word-selection rule. The fidelity check verifies agreement with the public renderer at shared settings. Install `requirements-selectors.txt` before running this command.

Generate selections independently for training and FRESH, at each desired rate. Here is the FRESH `cr=8` command:

```bash
python tools/llmlingua_select.py \
  --dataset_name sggetao/PwC \
  --dataset_split 'test[2100:5100]' \
  --decoder_tokenizer_name HuggingFaceTB/SmolLM2-1.7B-Instruct \
  --encoder_tokenizer_name answerdotai/ModernBERT-base \
  --max_prompt_len 512 \
  --max_answer_len 1024 \
  --max_source_len 1024 \
  --max_vision_len 1024 \
  --max_samples 0 \
  --budget_cr 8 \
  --device cuda \
  --search_mode threshold \
  --search_iters 32 \
  --fidelity_check_docs 25 \
  --seed 42 \
  --output_jsonl selections/llmlingua_fresh_cr8.jsonl \
  --stats_json selections/llmlingua_fresh_cr8_stats.json

python tools/audit_selection_jsonl.py \
  --jsonl selections/llmlingua_fresh_cr8.jsonl \
  --budget_cr 8 \
  --dataset_split 'test[2100:5100]' \
  --max_prompt_len 512 \
  --max_answer_len 1024 \
  --max_source_len 1024 \
  --max_vision_len 1024 \
  --expect_rows 3000 \
  --expect_docs 205 \
  --out_json selections/llmlingua_fresh_cr8_audit.json
```

Repeat selection with `--dataset_split train` and a separate output file. In the matched-reader training command, replace `--selection_policy first` with `--selection_policy file --doc_selection_file selections/llmlingua_train_cr8.jsonl` and keep `--truncate_cr 8`.

In the matched-reader evaluation command, replace `--doc_truncation first --doc_budget_cr 8` with `--doc_truncation file --doc_selection_file selections/llmlingua_fresh_cr8.jsonl`. Omit `doc_budget_cr` in file mode because the selector has already applied the budget. Point `sft_model_path` at the reader trained on those LLMLingua selections.

Selection indices refer to the filtered dataset order. Training and evaluation selection files are not interchangeable. Check that fidelity passed, no selection exceeds its cap, prefix truncation was not used, and shortfall statistics were saved. Exact cap utilization is not guaranteed by word-level selection. A reader trained on first-N contexts is a separate transfer condition when evaluated on LLMLingua selections.

## Generation and document-cluster intervals

Add `--compute_generation_metrics --max_new_tokens 256` to an evaluation command and use separate output paths to retain teacher-forced and generation artifacts. Per-example dumps then also contain predictions and references. The raw ROUGE/BLEU values emitted by evaluation differ from the paper's first-sentence analysis. Compressor targets omit EOS whereas SFT targets append it, so stopping behavior must be accounted for.

Create document identities for the exact evaluated slice, then rescore saved predictions:

```bash
python tools/length_controlled_gen.py \
  --make_doc_ids results/fresh_doc_ids.json \
  --dataset sggetao/PwC \
  --split 'test[2100:5100]'

python tools/length_controlled_gen.py \
  --dumps results/pool_project_cr8_gen_dump.jsonl results/first_n_cr8_gen_dump.jsonl \
  --labels pool first_n \
  --doc_ids results/fresh_doc_ids.json \
  --protocols raw first_sentence \
  --compare pool:first_n \
  --n_boot 5000 \
  --seed 42 \
  --out results/generation_comparison.json \
  --out_md results/generation_comparison.md
```

The document-ID builder uses raw slice positions. Use this direct mapping only after verifying that all 3,000 rows survive the filters and the dumps cover that same slice. The optional `trunc_char` and `trunc_word` protocols use reference length and are oracle diagnostics.

For paired NLL intervals, `llmlingua_report.py` can use a selection JSONL's document hashes as the cluster map for any aligned systems:

```bash
python tools/llmlingua_report.py \
  --clusters_jsonl selections/llmlingua_fresh_cr8.jsonl \
  --cell pool=results/pool_project_cr8_dump.jsonl \
  --cell first_n=results/first_n_cr8_dump.jsonl \
  --contrast pool:first_n \
  --expect_rows 3000 \
  --expect_docs 205 \
  --n_boot 5000 \
  --seed 42 \
  --out_json results/paired_nll_cr8.json
```

The contrast is NLL(pool) minus NLL(first-N). It resamples documents and recomputes token-pooled NLL. It requires equal sample-ID sets and answer-token counts across systems. Verify dataset, tokenizers, checkpoint, numerical mode, and filtering before interpreting a contrast. Intervals quantify held-out-document uncertainty conditional on the supplied trained models. They are not uncertainty over training seeds. `tools/bootstrap_ci.py` uses row resampling and does not implement the paper's document-cluster uncertainty.

## Scope of the available implementation

Changing the decoder model argument supports architecture experiments, but exact published Qwen results also depend on the archived run's numerical settings. The cluster Qwen launcher references a separate snapshot and sets `CVLM_EVAL_FP16`, which the current general evaluation entrypoint does not consume. Treat a new Qwen run from these commands as a new run with recorded settings, rather than claiming an exact reproduction of that archived evaluation.

Original judge outputs, manual annotations, full system-latency measurements, and representational-analysis dumps are not included in this checkout. The paper and poster provide the reported findings. The source includes several diagnostic helpers, but it is not a complete archive of every measurement behind the publication.
